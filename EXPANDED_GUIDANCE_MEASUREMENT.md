# Expanded guidance experiment: semantic measurement

Experiment 4B broadens source acquisition within the original 2024–2025 window
and original 100-company universe. It adds quarterly earnings, annual earnings
and preliminary-results filings to guidance issuance/update and withdrawal.
It does not broaden the economic category: only comparable full-year guidance
can qualify. The completed experiment 4 remains immutable. The expansion was
chosen after observing its source failure and is exploratory.

The source audit recovered 208 unique original SEC packages across 54 companies.
The deterministic extractor found potential ranges in 127 filings across 36
companies, exceeding the unchanged 80-filing/20-company source floors. All
packages validated. These are potential numerical candidates, not confirmed
forecasts. Eighty-one filings had no current bounded candidate. The source
protocol was committed as `f6360b8` before acquiring the additional filings.

## Ordered measurement

`expanded_guidance_semantics.py` freezes its exact implementation checksum,
question templates, evidence extractor, source-manifest digest, input digest,
units, thresholds and cost metadata before sending any JEV request. Model
`jev-1.13.0` is pinned. Every event has at most three requests:

1. Choose a current company-wide full-year guidance range, and independently
   identify its metric, disclosed currency/unit and fiscal year. Prefer adjusted
   diluted EPS; otherwise revenue level. Reject actual results, segment or
   quarterly forecasts, GAAP EPS, FFO, growth rates and unsupported currency.
2. Given the selected current range, choose the latest comparable earlier
   forecast for the same fiscal year, metric, accounting basis and scope. An
   explicitly labeled prior guidance column in the current exhibit is allowed.
   The identical physical source span is excluded from prior candidates.
3. Given both selected ranges, verify their comparability, identify the prior
   unit, score comparative forecast uncertainty, choose the semantic group, and
   select an exact current passage establishing any claimed change.

Batched answers cannot see one another. Selecting a range does not certify
that its independent metric or year classification is correct; the third
request checks the pair and exact evidence. Model confidence measures its
reported probability concentration, not calibrated factual accuracy.

Current/prior range selection, metric, units, year and pair validation require
probability at least 0.80. Changed groups require a selected original passage
with probability at least 0.75 and a comparative score with the corresponding
sign. An unchanged group cannot claim changed-state evidence. Missing evidence
means unknown; numerical width changes and generic confidence language do not
establish a semantic change. The fixed five-level uncertainty Score is shifted
by minus two, so positive values indicate deterioration.

## Source and numerical integrity

All range options retain exact normalized-document offsets, document hashes,
original SEC URLs, filenames, accession identity and acceptance timestamps.
Evidence options use the selected current range context and original document
lines matching the frozen visibility/contingency/guidance cue, with two adjacent
nonempty lines each side. Overlapping passages merge; unrelated source text is
never generated by the model. Quote integrity is checked against the original
parsed source. An event exceeding 254 evidence passages is excluded explicitly.

Python reparses the exact range quote using Decimal arithmetic. Revenue becomes
USD million; EPS remains USD/share. The prior midpoint must be positive. The
primary cohort requires absolute midpoint change at most 2%. Fiscal year and
accounting comparability are semantic judgments, not an externally verified
gold label. The analyst review specified in the source protocol remains
mandatory before any economic data can be opened.

The forecast-age covariate is the difference between source filing dates. For
an explicitly labeled prior forecast in the same exhibit it is zero. It is a
citation-age proxy, not verified first-publication age. The keyword covariate
uses the frozen current-minus-prior substring-presence lexicon.

## Capacity, retries and gates

The official model documents a 32k-token state-plus-longest-question limit.
This implementation uses a conservative 30,000 UTF-8-byte ceiling for the full
serialized request, excluding oversized requests instead of silently truncating
evidence. This may reject inputs the service could accept; capacity attrition
is reported explicitly. Candidate and evidence option maps never exceed 255
including abstention. This executable capacity rule is frozen before labels;
it does not lower the source or semantic feasibility floors.

Requests and raw responses are immutable and keyed by the frozen specification
and exact request. Successful malformed responses are retained and excluded;
they are never resampled. Transport errors, HTTP 429/529 and server errors have
at most four attempts with 1/2/4-second backoff. Other HTTP failures stop the run
with explicit diagnostics. A completed measurement is verified and reused.

Economic analysis requires all unchanged semantic safeguards: at least 80
eligible events, 20 companies, effective company count 20, largest issuer share
at most 15%, malformed fraction at most 5%, uncertainty standard deviation at
least 0.35, and at least 15 explicit changes from eight companies. Effective
company count is the inverse sum of squared event shares. These safeguards do
not establish statistical power. A failed gate blocks all market calls.

Actual request latency and response token usage will be reported. Estimated
JEV usage cost uses the official October 3, 2026 price of $0.042 per million
input tokens, with output tokens free; this is a rate-based estimate rather than
an account invoice. Massive subscription costs and transaction-cost scenarios
are separate quantities.

## Reproduction

```bash
.venv/bin/python expanded_guidance_sources.py verify
.venv/bin/python -m unittest test_expanded_guidance -v
.venv/bin/python expanded_guidance_semantics.py freeze
# Commit the measurement implementation before the first model request.
.venv/bin/python expanded_guidance_semantics.py measure
```

The run artifacts live in ignored `expanded_guidance_results/`; the source and
measurement manifests reject changed files. Do not delete successful response
records to retry a label, change thresholds to make a gate pass, or open the
notebook's 2026 cells. There is no OOS or judges-window command in this pipeline.
